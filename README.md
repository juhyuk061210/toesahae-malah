# 퇴사해말아?

직장인 대상 퇴사운 사주 리포트. 질문 답변과 사주 명식을 겹쳐 읽어
"지금 흔들리는 이유"를 정리해주는 웹 서비스입니다.

> **지금은 체험판입니다.** 무료 진단까지만 열려 있고, 결제와 상세 리포트는
> 사업자 등록·결제 연동을 마친 뒤 엽니다.

---

## 무엇이 다른가

대부분의 사주 서비스는 미리 써둔 문장을 조립합니다. 그래서 "다 똑같은 말"이라는
평을 받습니다. 이 서비스는 두 가지를 다르게 합니다.

**1. 모든 판단에 근거를 답니다**

> "소속을 원하면서도 그 소속이 오래 버텨주지 않는 구조"
> — 천간 관성 기 + 년지 미에 통근 + 합거 + 형충 손상

근거를 달 수 없는 문장은 아예 만들지 않습니다. 근거 없는 단정은
누구에게나 맞는 빈 말이 되기 때문입니다.

**2. 답변끼리 부딪혀 읽습니다**

> "퇴사 생각은 거의 매일. 그런데 언제까지 버틸지도, 나갔을 때 몇 달을
> 버틸 수 있는지도 계산해본 적이 없다고 답하셨습니다."

사주가 아니라 본인 답변 세 개를 겹쳐 본인이 말하지 않은 함의를 짚습니다.
흔한 조합은 "당신만의 것"이라고 부르지 않습니다 — 등급제로 막아둡니다.

## 정확도

| 검증 | 결과 |
|---|---|
| 사주 명식 (외부 만세력 대조) | 8,456건 전수 일치 |
| 명식 회귀 테스트 | 50/50 |
| 음력 → 양력 변환 | 40,190건 검증 / 회귀 80/80 |
| 명리 규칙표 자가검증 | 1,237건 |
| 긴장 탐지 규칙 | 371건 |

명리 규칙(지장간·십이운성·형충회합·용신·격국·신살)은 문헌 조사 후
별도 검증을 거쳐 오류 60건과 누락 62건을 수정한 뒤 반영했습니다.

## 구조

```
questions.js     질문지 (결제 전 10 + 결제 후 8)
bridge.js        답변 → 점수 변환
tension.js       답변 간 긴장 탐지 (규칙 33개)

saju.js          만세력 · 사주팔자
solar-terms.js   절기표 (1930~2040, 분 단위)
lunar-table.js   음력 변환표
saju-deep.js     명리 표
saju-analyze.js  판정 (사령·신강약·격국·용신·신살)
saju-read.js     통변 — 판정을 해석으로

diagnosis.js     점수 · 유형 · 12개월 흐름
narrative.js     서술 (AI 프롬프트 + 규칙 기반 폴백)
server.js        정적 서빙 · SQLite · LLM 프록시
```

외부 의존성이 없습니다. Node 22+ 내장 모듈만 씁니다.

---

## 실행

```bash
node server.js                          # http://localhost:8080
ANTHROPIC_API_KEY=sk-... node server.js  # AI 서술까지
```

정적 호스팅에서도 **무료 진단은 전부 동작**합니다. 사주 계산과 긴장 탐지가
브라우저에서 돌기 때문입니다. 상세 리포트의 AI 서술만 서버가 필요합니다.

## 테스트

```bash
node tests/run.js       # 사주 명식
node tests/lunar.js     # 음력 변환
node tests/deep.js      # 명리 표
node tests/tension.js   # 긴장 탐지
node tools/quality.js   # 리포트 품질 계측
```

## 정식 오픈 전 남은 것

- `config.js` 의 `biz` 항목 (전자상거래법 필수 표시사항)
- 법적 문서 3종의 `[대괄호]` 치환
- 결제 연동 및 `server.js` 의 결제 검증 블록
- `config.js` 의 `demo: false`

자세한 내용은 `LAUNCH.md` 를 보세요.

## 고지

사주명리 기반의 자기이해 콘텐츠입니다. 결과는 미래를 보장하지 않으며
퇴사·이직 같은 결정을 대신하지 않습니다. 실제 판단에는 재정 상황과
채용 시장을 함께 놓고 보시기 바랍니다.
